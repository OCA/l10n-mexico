This module adds Mexican CFDI Carta Porte (waybill) support for
inventory transfers. It provides simplified fleet management with
vehicles, transporters, and waybill generation linked to stock pickings.

**Table of contents**

.. contents::
   :local:

Configuration
=============

Configure vehicles, transporters, and CFDI issuers before creating
waybills from inventory transfers.

Usage
=====

Create a waybill from a stock picking or from the Waybills menu,
complete the required transport data, and publish the CFDI.
