To use this module, you need to:

1. Go to Accounting > Customers > Invoices
2. Create an invoice for the partner configured with **Addenda Kuehne Nagel**
3. Set the Customer Reference for the Purchase Order when applicable
4. Open the **Kuehne+Nagel Addenda** tab and optionally fill:

   - File / Tracking Type
   - File / Tracking Number
   - Branch Centre
   - Transport Ref

5. Validate and stamp the invoice as usual

The module does not enforce a format for the Customer Reference or addenda fields.
