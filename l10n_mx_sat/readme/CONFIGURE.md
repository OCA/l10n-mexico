1. Instalar la libreria cfdiclient: `pip install cfdiclient`
2. Ir a Facturacion -> Configuracion -> Ajustes
3. En la seccion "Conexion SAT", subir el certificado FIEL (.cer) y la llave privada (.key)
4. Ingresar la contrasena de la llave privada
5. Hacer clic en "Probar conexion" para verificar que las credenciales son correctas
