1. Go to *Accounting > Customers > Invoices*.
1. Create an invoice for the Volkswagen partner.
1. Set the customer reference (purchase order) if required.
1. In the *Addenda Volkswagen* tab, fill in the division, applicant name and
   applicant email.
1. On each invoice line, set the VW product reference (part number).

When the CFDI is stamped, the Volkswagen addenda QWeb template is applied to
the XML by the CFDI account addenda framework.
